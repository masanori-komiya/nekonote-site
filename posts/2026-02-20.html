PythonでCSVを自動処理する方法

業務でCSVファイルを扱う機会は多いですが、毎回手作業で開いて整理するのは時間のムダです。Pythonを使えば、CSVの読み込み・加工・出力をすべて自動化できます。この記事では、実務でよく使うパターンを紹介します。

基本の読み込みと書き出し

Pythonの標準ライブラリ csv モジュールを使えば、インストール不要でCSVを扱えます。

import csv

# 読み込み
with open('input.csv', newline='', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    rows = [row for row in reader]

# 加工（例：金額に消費税を加算）
for row in rows:
    row['金額'] = str(int(row['金額']) * 1.1)

# 書き出し
with open('output.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.DictWriter(f, fieldnames=rows[0].keys())
    writer.writeheader()
    writer.writerows(rows)

pandasを使った応用例

より複雑な処理には pandas ライブラリが便利です。複数ファイルの結合やフィルタリングもシンプルに書けます。

import pandas as pd

# 複数CSVを結合
df1 = pd.read_csv('data_jan.csv')
df2 = pd.read_csv('data_feb.csv')
df = pd.concat([df1, df2])

# 特定条件でフィルタ
df_filtered = df[df['売上'] > 10000]

# 集計
summary = df_filtered.groupby('担当者')['売上'].sum()
summary.to_csv('summary.csv', encoding='utf-8')

定期実行と組み合わせる

このスクリプトをスケジューラーやGitHub Actionsと組み合わせれば、毎日自動で集計レポートを生成できます。手作業ゼロで最新データを常に確認できる環境が作れます。

まとめ

PythonのCSV処理は、標準ライブラリだけでも十分実用的です。繰り返し発生するデータ整理作業は、一度スクリプト化してしまえば以降はボタン一つで完了します。業務効率化の第一歩として、ぜひ試してみてください。
