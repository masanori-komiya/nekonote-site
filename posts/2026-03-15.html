AIでPDFや画像から文字を読み取る（OCR）入門

紙の書類をスキャンしたPDFや、写真に写った文字をデータ化したい——そんな場面で活躍するのがOCR（光学文字認識）技術です。近年はAIの進化により、精度が大幅に向上しています。Pythonからも手軽に使えるようになりました。

PythonでOCRを使う主な選択肢

  • Tesseract + pytesseract: オープンソースで無料。日本語も対応可能
  • Google Cloud Vision API: 高精度。クラウド経由でAPIを呼び出す
  • ChatGPT Vision (GPT-4o): 画像を直接渡して文字起こし・解釈まで可能

pytesseractの基本的な使い方

pip install pytesseract pillow
  
import pytesseract
from PIL import Image

# 画像を開いてOCR
image = Image.open('receipt.png')
text = pytesseract.image_to_string(image, lang='jpn')
print(text)

事前にTesseractのインストールと日本語データ（jpn.traineddata）の追加が必要です。

GPT-4oで画像の内容を読み取る

より高度な読み取りや、内容の解釈が必要な場合はGPT-4oのVision機能が便利です。

import base64
import openai

client = openai.OpenAI()

with open("invoice.png", "rb") as f:
    image_data = base64.b64encode(f.read()).decode("utf-8")

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "この請求書から合計金額と請求日を読み取ってください。"},
                {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{image_data}"}}
            ]
        }
    ]
)
print(response.choices[0].message.content)

業務での活用例

  • 領収書・請求書のデータ入力を自動化
  • 名刺の情報をCSVに変換
  • 手書きフォームのデジタル化
  • 古い紙資料のテキスト検索可能なデータベース化

まとめ

OCR技術とAIを組み合わせることで、これまで手作業だった「紙→データ」の変換を自動化できます。定型フォーマットの書類であれば精度も高く、入力ミスの削減にも直結します。書類処理の多い業務には特に効果的です。
