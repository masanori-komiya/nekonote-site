PythonでWebスクレイピング入門

「競合他社の価格を毎日チェックしたい」「特定サイトの新着情報を自動で取得したい」——こういった情報収集作業を手作業でやるのは非常に手間です。Pythonのスクレイピングを使えば、Webページから必要な情報を自動で取得できます。

基本ライブラリの準備

pip install requests beautifulsoup4

基本的なスクレイピングの流れ

import requests
from bs4 import BeautifulSoup

# ページを取得
url = "https://example.com/news"
response = requests.get(url, headers={"User-Agent": "Mozilla/5.0"})
response.encoding = response.apparent_encoding

# HTMLを解析
soup = BeautifulSoup(response.text, "html.parser")

# タイトル一覧を取得
titles = soup.select("h2.article-title")
for title in titles:
    print(title.get_text(strip=True))

取得したデータをCSVに保存

import csv

items = []
for article in soup.select("div.article"):
    title = article.select_one("h2").get_text(strip=True)
    date = article.select_one("time").get_text(strip=True)
    items.append({"タイトル": title, "日付": date})

with open("news.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["タイトル", "日付"])
    writer.writeheader()
    writer.writerows(items)

注意点

  • 利用規約の確認: スクレイピングを禁止しているサイトもあります。robots.txtや利用規約を事前に確認してください。
  • アクセス頻度: 短時間に大量のリクエストを送るとサーバーに負荷をかけます。time.sleep() で間隔を空けましょう。
  • JavaScriptページへの対応: JS描画が必要なページにはSeleniumやPlaywrightを使います。

定期実行との組み合わせ

スクレイピングスクリプトをGitHub Actionsや定期実行ツールと組み合わせることで、毎日自動で情報収集→CSV保存→通知、というフローを無人で回せます。

まとめ

Webスクレイピングは情報収集の自動化において非常に強力な手法です。requests＋BeautifulSoupの組み合わせはシンプルで学習コストも低く、多くのサイトに対応できます。毎日手動でチェックしているWebページがあれば、まず自動化を検討してみてください。
