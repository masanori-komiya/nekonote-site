ChatGPT APIをPythonで使う入門ガイド

OpenAIが提供するChatGPT APIを使えば、自分のPythonプログラムにAIの自然言語処理機能を組み込めます。文章の要約・分類・翻訳など、様々な業務自動化に応用できます。この記事では基本的な使い方を解説します。

セットアップ

まずOpenAIライブラリをインストールし、APIキーを設定します。

pip install openai
  
import openai

client = openai.OpenAI(api_key="your-api-key")

APIキーは環境変数で管理するのが安全です。

import os
import openai

client = openai.OpenAI(api_key=os.environ["OPENAI_API_KEY"])

基本的なテキスト生成

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "あなたは業務効率化の専門家です。"},
        {"role": "user", "content": "毎日のメール整理を効率化する方法を3つ教えてください。"}
    ]
)

print(response.choices[0].message.content)

業務への応用例

AIを業務フローに組み込む具体的な活用例を紹介します。

  • メール文面の自動生成: テンプレートと差し込みデータを渡してメール文面を生成
  • 議事録の要約: 長文テキストを短くまとめる
  • カテゴリ分類: 問い合わせ内容を自動でラベリング
# 問い合わせ内容を自動分類する例
def classify_inquiry(text):
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "問い合わせを「請求」「技術」「その他」のいずれかに分類してください。カテゴリ名だけ返してください。"},
            {"role": "user", "content": text}
        ]
    )
    return response.choices[0].message.content.strip()

category = classify_inquiry("先月の請求書が届いていないのですが確認できますか？")
print(category)  # → 請求

まとめ

ChatGPT APIは数行のコードで使い始めることができます。繰り返し発生するテキスト処理業務にAIを組み込むことで、作業時間を大幅に削減できます。まずは小さな業務から試してみることをおすすめします。
