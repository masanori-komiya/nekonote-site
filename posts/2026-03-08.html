Pythonで業務を定期実行する方法

「毎朝9時に売上データを集計したい」「毎週月曜日にレポートをメールしたい」——こういった定期実行の仕組みは、Pythonといくつかのツールを組み合わせることで簡単に構築できます。

方法1：scheduleライブラリを使う

Pythonスクリプト内でスケジューリングするシンプルな方法です。

pip install schedule
import schedule
import time

def daily_report():
    print("レポートを生成しています...")
    # ここに処理を書く

def weekly_email():
    print("週次メールを送信しています...")
    # ここに処理を書く

schedule.every().day.at("09:00").do(daily_report)
schedule.every().monday.at("08:00").do(weekly_email)

while True:
    schedule.run_pending()
    time.sleep(60)

ただしこの方法はスクリプトを常時起動しておく必要があります。

方法2：GitHub Actionsで定期実行

サーバーが不要で、GitHubのCI/CDを使って定期実行できます。無料枠の範囲内で多くの用途をカバーできます。

name: Daily Task

on:
  schedule:
    - cron: '0 0 * * *'  # 毎日UTC 0時（日本時間9時）

jobs:
  run:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - run: pip install -r requirements.txt
      - run: python scripts/daily_task.py

方法3：Windowsタスクスケジューラ / cron

ローカルPCやサーバーで実行する場合は、OSのスケジューラが利用できます。

  • Windows: タスクスケジューラでPythonスクリプトのパスを登録
  • Linux/Mac: crontab -e でcronジョブを設定
# 毎日午前9時に実行（cron設定例）
0 9 * * * /usr/bin/python3 /home/user/scripts/task.py

まとめ

定期実行の仕組みは一度作ってしまえば、あとは完全に自動で動き続けます。用途に合わせてscheduleライブラリ・GitHub Actions・OSのスケジューラを使い分けると効率的です。「毎回手動でやっている作業」があれば、まず定期実行化を検討してみてください。
